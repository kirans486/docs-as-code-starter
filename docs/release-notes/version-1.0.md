# APIConnect 1.0 Release Notes

**Release date:** November 10, 2026

## Overview

APIConnect 1.0 introduces a centralized platform for registering, securing, publishing and monitoring APIs.

This release provides the foundational capabilities required to manage APIs and control access for API consumers.

## New features

### API Management

- Register APIs in a centralized API catalog.
- Configure API names, versions and endpoint paths.
- Manage registered API information.

### Security and Access

- Generate API access tokens.
- Configure token permissions.
- Define token expiration periods.
- Revoke tokens when they are no longer required.

### API Consumption

- Invoke registered APIs using authenticated HTTP requests.
- Support Bearer token authentication.
- Return standard HTTP response codes.

### Documentation

- Getting Started guides.
- API registration procedures.
- API token management instructions.
- API request examples.
- Architecture overview.

## Known limitations

- API analytics capabilities are planned for a future release.
- Advanced API lifecycle management is not included in this release.
- The platform examples use fictional API endpoints.
