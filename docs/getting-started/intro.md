# Introduction to APIConnect

## Overview

APIConnect is an API management platform that helps organizations design, publish, secure and monitor APIs through a centralized interface.

It provides tools for API developers, administrators and consumers to manage the API lifecycle and simplify API integration.

## Key capabilities

| Capability | Description |
|---|---|
| API Management | Register, configure and publish APIs. |
| API Gateway | Manage API routes and incoming requests. |
| Security and Access | Configure authentication, tokens and access policies. |
| Developer Portal | Allow consumers to discover and subscribe to APIs. |
| Analytics and Monitoring | Track API traffic, errors and usage patterns. |

## Who should use this documentation?

This documentation is intended for:

- **API Administrators:** Manage users, permissions and platform configurations.
- **API Developers:** Register, configure and publish APIs.
- **API Consumers:** Discover APIs and obtain access credentials.
- **Platform Operators:** Monitor API traffic and troubleshoot issues.

## Getting started

If you are using APIConnect for the first time, follow these steps:

1. Review the [Platform Architecture](./architecture.md).
2. Check the [Quick Start Guide](./quick-start.md).
3. Follow the user guides to register and manage APIs.
